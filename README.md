# Security Engineer (AI + Cloud)

I build Python tools that automate security across cloud infrastructure and AI systems.

## Scope

Work published here includes:
- Cloud misconfiguration scanning across AWS accounts: public buckets, IAM without MFA, open network access, missing logs, root account activity
- LLM prompt injection testing against the OWASP LLM Top 10
- AI-generated code security scanning: missing authentication, SQL injection, hardcoded secrets, exposed API keys
- Automated CI/CD security pipelines: SAST, dependency scanning, secret scanning

## Areas of Focus

- Cloud security: AWS IAM, VPC and private subnets, Secrets Manager, CloudTrail, CloudWatch
- AI and LLM security: OWASP LLM Top 10, prompt injection, adversarial testing
- DevSecOps: CI/CD automation with Bandit, Semgrep, pip-audit, Gitleaks
- Threat detection: log analysis, authentication attack detection, network monitoring, MITRE ATT&CK
